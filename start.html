Getting started

Six steps, about ten minutes. Nothing to install.

  1. Create your account

    One login for your agency. Share it with whoever does the reporting.

    Sign up

  2. Add a client

    One workspace per client. Name it after them.

  3. Connect Google Ads

    Sign in with the Google account that reaches that client’s ads. Roster only ever reads.

    Google expires this every 7 days during early access — you’ll reconnect weekly until we’re verified.

  4. Pick the accounts

    Search the accounts that login can reach and add this client’s.

    Manager accounts (MCC) can’t be added — Google won’t report metrics on them. Add the account underneath.

  5. Connect Claude

    In Claude → Settings → Connectors → Add custom connector, paste this:

    https://roster-1035727789436.asia-southeast1.run.app/api/mcp

    Works in Claude Desktop and on claude.ai. First use opens a browser to approve. Once only.

    Using Claude Code? Install the plugin instead

    Adds commands and report-building agents on top of the connector. Claude Code terminal only — /plugin does not exist elsewhere.

    Run these one at a time. The first opens a prompt asking for the source — paste only what you copy here, nothing more.

    /plugin marketplace add GauravKumar1905/roster-plugin
    /plugin install roster@roster
    /roster:setup

    If a prompt asks for a marketplace source on its own, it wants just GauravKumar1905/roster-plugin.

  6. Ask for a report

    Build a monthly performance report for Northside Coffee.

    Claude shows you the figures before saving. You get a link to send your client — it refreshes itself from then on.

Already have a report format?

Share the spreadsheet or PDF you send today and ask Claude to match it. It becomes a template, and every client after that is one step.

If something goes wrong

“This is a manager account”
Add a client account underneath the MCC instead.
Fewer widgets than expected
Ones needing data the account lacks are skipped, not shown empty. The report lists which.
“No Google connection”
The 7-day expiry. Reconnect in that workspace’s settings.
Claude can’t see your clients
It’s signed into a different Roster account, or the connector was never approved. Remove and re-add it. On Claude Code, run /roster:setup.
